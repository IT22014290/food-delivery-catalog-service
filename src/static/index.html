Inter-Service Communication

Demonstrates the POST /api/v1/menu-items/bulk-lookup endpoint used by the Order Service.

🔗 How it works

When a customer places an order, the Order Management Service calls this endpoint with a list of menu item IDs. The Catalog Service validates each item exists and is currently available, then returns the item details (including price) for order total calculation. Items that are unavailable or not found are returned in the unavailable_ids list.

ℹ This is an internal service endpoint — no JWT required. The Order Service uses it server-to-server with an X-Internal-Service header.
